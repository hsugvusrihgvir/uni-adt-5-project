# Распределение домашних обязанностей

Консольное приложение для организации домашних задач и распределения обязанностей между пользователями.

## Возможности

* просмотр и добавление домашних задач;
* поиск задачи по части названия;
* фильтрация задач по категории;
* сортировка задач по названию;
* проверка, назначен ли задаче ответственный;
* назначение и снятие ответственного;
* установка срока выполнения;
* изменение статуса задачи;
* просмотр статистики выполнения;
* загрузка и сохранение данных в JSON.

## Структура проекта

* `main.py` - точка запуска и меню приложения;
* `tasks.py` - все операции с домашними задачами;
* `task_statistics.py` - подсчёт статистики;
* `storage.py` - загрузка и сохранение данных;
* `utils.py` - проверка пользовательского ввода;
* `data/tasks.json` - домашние задачи и данные об их выполнении;
* `tests/` - автоматизированные тесты.

Классы и объекты на данном этапе не используются. Данные представлены списками и словарями.

## Формат данных

Домашняя задача:

```json
{
    "id": 1,
    "name": "Помыть пол",
    "category": "Уборка",
    "responsible_user": "Даша",
    "deadline": "2026-09-23",
    "status": "Не выполнена"
}
```

Если ответственный и срок ещё не заданы, их значения равны `null`, а статус
задачи - `Не назначена`. Дата хранится строкой в формате `ГГГГ-ММ-ДД`.

## Требования

* Python 3.x;
* pytest;
* flake8.

Установка инструментов:

```bash
python -m pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
python -m pytest
```

## Проверка кода

```bash
python -m flake8 .
```
