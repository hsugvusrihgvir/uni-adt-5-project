# Распределение домашних обязанностей

## Назначение

Веб-приложение для организации и распределения домашних обязанностей между людьми, проживающими совместно. Приложение позволяет создавать задачи, назначать ответственных и отслеживать их выполнение.

## Целевая аудитория

Семьи, пары, соседи по квартире, студенты в общежитии и другие люди, которые совместно проживают и хотят организовать выполнение домашних дел.

## Предметная область

Предметная область проекта - организация совместного быта. Она включает создание домашних задач, распределение обязанностей между участниками, установку сроков выполнения и контроль состояния задач.

## Основные сущности

* пользователь;
* группа пользователей;
* домашняя задача;
* расписание;

## Основные функции

* создание и управление домашними задачами;
* назначение ответственного за выполнение задачи;
* установка срока выполнения задачи;
* изменение статуса задачи;
* просмотр текущих и выполненных задач;
* объединение пользователей в общую группу.

## План развития

На следующих этапах планируется:

* разработка веб-приложения;
* подключение базы данных;
* реализация пользователей;
* разработка API;
* контейнеризация приложения;
* настройка CI/CD.
